Getting Ready for Using Finches

Before Students Begin

  1. Print the bluetooth name of each Finch onto a piece of tape and attach it to the Finch.
    2. Show Example Image
  2. Go over classroom expectations for using the Finches.

Setting up in FinchBlox

  1. Connect the Finch to student devices using Bluetooth by selecting the option on the computer that matches the Finch's Bluetooth name. It is recommended to do this for the first time in small groups.
    2. Show How to Connect the Finch
  2. Ensure that students know they need a green flag in a yellow to run a program using the green flag at the top. They can also test what sections of code do by clicking them.

Setting up in MakeCode

  1. Make sure each Finch has a USB mini-B cable with it.
  2. Start a new MakeCode project.
    3. Show How to Start a New MakeCode Project
  3. Add the Finch extension to MakeCode.
    4. Show How to Add the Finch Extension
  4. Add the "start Finch" block anytime you are programming the Finch. If you are just programming the micro:bit, you don't need to add this block.
  5. To download code, plug the USB mini-B cable into the micro:bit, not into the USB-C spot in the base of the Finch. Make this easier by having the side with the icon and B facing you. In MakeCode, click download and the code will copy to the micro:bit.
    6. Show USB mini-B icon
    Show USB mini-B Connected
    Show Download in MakeCode

    Additional Tips

  6. Delete the Forever Loop by right-clicking on it and dragging it to the trash on the left. At this stage of coding, forever loops have a limited value and will cause more of a headache than it is worth.
    7. Show Deleting the Forever Loop
  7. Discuss placing code directly under "on start" with students. Anything placed under "on start" will run as soon as the Finch is turned on. One fun thing to do is to add a heart icon to let students know their FInch is "alive"
    8. Show Adding a micro:bit Icon

Switching from MakeCode to FinchBlox

  1. Download the firmware below.
  2. Connect the micro:bit to the computer using the USB mini‑B cable.
  3. Open the files folder and locate BBTFirmware.hex.
  4. Right‑click and drag it to the "MICROBIT (D:)" drive to drop it and it will copy over.
